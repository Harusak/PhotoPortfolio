# Handoff: Journal 一覧 — フォーカス操作（マウス／タッチ）

> Journal 一覧（`README.md`）の続きです。配置・`docs/` の `exclude`・トークン・フォントの前提は README と同じです。
>
> **2026-11 追加**：README の「タッチ端末ではホバーが無いため、Depth of field の効果は実質かからない」を置き換えます。一覧で「どのカードにピントを合わせるか」を入力方式ごとに定義し、両方で同じ **AF ブラケット** を使います。README のボケ・視差の式はそのまま使います。

## Overview
- **マウス方式**：OS のカーソルを消し、描いたカーソル（小さな四隅ブラケット）がページの上を動く。カードに乗るとブラケットがそのカードの写真の外周まで広がって「ロック」する。カーソルがそのままカードに拡張される表現
- **タッチ方式**：画面に固定の **合焦ライン** を置き、スクロールするだけでラインに重なったカードにピントが合う。横に並んだカードは、指を置いた位置から左右に少しずらすだけで列を移る（**相対的な列切替**）。操作している間だけ同じ AF ブラケットが指先から現れ、ピントの合ったカードに広がる
- 2 つは **入力で切り替える**（画面幅ではない）。タッチ対応ノート PC や、トラックパッド付きの iPad でも、直前に使った入力に合わせてその場で切り替わる
- タップ／クリックは常に即座にリンクを開く（2 回タップは不要）
- Gallery の Albums 一覧にも同じ仕組みを使える（今回の対象は Journal のみ）

## 入力方式の判定

| 段階 | 判定 | 方式 |
|---|---|---|
| 初期値 | `matchMedia("(hover: hover) and (pointer: fine)").matches` | true → マウス／false → タッチ |
| 以後 | `pointerdown` / `pointermove` の `pointerType` | `mouse` → マウス／`touch` `pen` → タッチ |

- 方式は `document.documentElement.dataset.input = "mouse" | "touch"` に持ち、CSS と JS の両方から参照する
- **疑似マウスイベントに注意**：タップの後、ブラウザは `mouseenter` / `mousemove` などを疑似的に送る。ホバー系の処理は **Pointer Events で `pointerType === "mouse"` のときだけ** 動かす（`mouseenter` / `mousemove` は使わない）
- カーソルを消す CSS はマウス方式のときだけ：`html[data-input="mouse"] .journal, html[data-input="mouse"] .journal * { cursor:none }`（メディアクエリでは判定しない。併用端末で誤るため）
- カラム数は今どおりコンテナ幅で決める（README の Masonry）。方式とは独立
- 途中で方式が替わっても、ピントの合っているカード（`focusKey`）とピント面はそのまま引き継ぐ。ブラケットは、マウスならポインタの位置から、タッチなら指を置いた位置から、改めて広がる

## 共通のフォーカスモデル
両方式とも、次の 2 つを決めれば残り（ボケ・視差・ブラケット）は同じ実装で描ける。

| 値 | マウス方式 | タッチ方式 |
|---|---|---|
| `focusKey`（ピントの合ったカード） | ポインタの下のカード | 合焦ラインで選ばれたカード |
| 視差の基準点 | グループ内のポインタ位置（README どおり） | ピントの合ったカードの中心（補間あり、後述） |

- カードは `data-card` を持つ `<a>`。ヒーロー 3 枚は 1 つのグループ（`hero`）、Archive は年ごとのグループとして扱う
- ピント面・ボケ・opacity・視差の式は README の Hero／Archive の節と同じ

## AF ブラケット（共通の見た目）
- 固定のオーバーレイ（`position:fixed; inset:0; pointer-events:none; z-index:120; aria-hidden="true"`）の中に置く。モバイルの sticky ヘッダーの下になる重なり順でよい
- 枠：四隅のみ。各 11×11px、`1.5px solid currentColor`、色 `--ink`
- ラベル：枠の上（`bottom:calc(100% + 8px)`、モバイルは 7px）、左揃え。`● AF` ＋ 距離（gap 14px、モバイル 12px）。IBM Plex Mono 10px、0.14em、uppercase。丸は 6px、`currentColor`
- 大きさと位置（`x, y, w, h`）は毎フレームばねで追う：`v = (v + (target − cur) × 0.2) × 0.64; cur += v`（少し行き過ぎてから止まる＝ロックの手応え）

## マウス方式
- **カードの外**：22×22px の枠をポインタ中心に置く（押している間は 14×14px）。ポインタ位置に 4px の点（`--ink`、丸）
- **カードの上**：枠の目標 = カードの写真（`img`）の矩形を **10px** 外へ広げたもの（押している間は 3px）。点は消す
- **どのカードの上か**：毎フレーム `document.elementFromPoint(x, y).closest("[data-card]")`。ポインタを動かさずにホイールでスクロールしたときも追従させるため
- **ラベル**：カードの上にいる間だけ opacity 1（`transition: opacity .25s`）。距離はそのカード自身の奥行き面（ヒーロー：`distAt(idx/2)`、Archive：`distAt(z/den)`。`distAt` は README のステータス表示の距離と同じ式）
- **表示／非表示**：動かしている間は opacity 1。最後の移動・スクロールから 900ms 経ったら 450ms かけて 0 へ（実際の値は `opacity += (目標 − opacity) × 0.18` で追う）。ポインタがウィンドウの外に出たら消す
- 既存の `a:hover { opacity:.65 }` はそのまま
- ボケ・視差・ピントは README のまま（CSS transition。ブリージングは入れない）

## タッチ方式

### 合焦ライン
- 位置：ビューポートの高さ `h` に対して `y = h × (0.4 + 0.42·t)`。`t = clamp((scrollTop − (max − 0.7h)) / 0.7h, 0, 1)`、`max = scrollHeight − h`。最後の 0.7 画面分ではラインが下へ滑り、最後のカードにも届く
- ラインは表示しない（プロトタイプの `guide` は検証用）
- 判定：`scroll` を rAF で間引き、全カードについて次の得点を計算し、最小のカードを `focusKey` にする
  - `d` = ラインからカードの矩形までの縦の距離（ラインが中にあれば 0）
  - `dx` = 選択中の列の中心 x からカードの矩形までの横の距離（中にあれば 0）
  - `score = d × 1000 + (dx > 0 ? 200000 + dx × 1000 : 0) + |カード中心 y − ライン y|`
  - 選択中の列にあるカードが、ラインから 200px 以上離れていない限りそちらを優先する。ヒーローのメイン（全幅）はどの列にも属する
- **ヒステリシス**：今のカードが選択中の列にあり、ラインとの距離が 16px 以内なら、他が近くても今のカードのまま（視差でカードが少し動くため）
- 方式は **AF-C**（スクロール中も常に追従）

### 列の切替（相対）
- 列の中心 x：`(col + 0.5) / 列数 × 幅`。初期値は 0（左端の列）
- `touchstart`：基準 `x0` = 指の x、`c0` = 現在の列
- `touchmove`：`dx = x − x0`、`T = 12px`
  - `shift = dx > T ? +1 : dx < −T ? −1 : 0`。一度越えたら、戻しても `±T/2` までは `shift` を保つ（縦スクロール中の自然な横ぶれで行き来しないため）
  - `col = clamp(c0 + shift, 0, 列数 − 1)`。変わったらすぐ判定し直す
  - **3 列以上**（タブレット）：しきい値を越えるたびに `x0` をその時点の指の位置に置き直し、`c0` を更新して 1 列ずつ進められるようにする（プロトタイプは 2 列のみ）
- 指を離しても列は保持（慣性スクロール中も、次に指を置いたときも、その列から）
- 左右の反転（`invert`）は不採用

### AF ブラケット（タッチ）
- 普段は表示しない。`touchstart`・スクロール・列切替のたびに「最後に操作した時刻」を更新する
- **出現**：opacity が 0.03 未満の状態で操作が始まったら、枠を **指を置いた位置に 22×22px** で置いてから、ばねでカードへ広げる（マウス方式のカーソルと同じ大きさから始めることで、指先がカードに広がって見える）。指以外のスクロール（キーボードなど）ではカードの中心から
- **目標**：ピントの合ったカードの写真を 10px 外へ広げた矩形（指を置いている間は 6px）
- **列切替の前触れ**：しきい値に届くまでは、枠の x を `clamp(dx, −T, T) × 0.7` だけずらす（指に引かれて傾く）。越えたら隣のカードへばねで移る
- **ラベル**：枠がロックしたら（目標との差が幅・x とも 6px 未満）表示。opacity は `+= (目標 − 現在) × 0.2`。距離は現在のピント面（`distAt(zv/den)`、`zv` は後述の補間値）
- **opacity**：指を置いている間は 1。離したら最後の操作から 900ms 後に 450ms かけて 0。値は増えるとき `× 0.35`、減るとき `× 0.18` で追う
- 旧案の AF 点（丸）・カード内の AF 枠・合焦ラインのガイドは実装しない

### ピント送り・ブリージング・視差（タッチ）
- **ピント送り**：グループごとの目標面 `zf` に対し、表示用の面 `zv` を毎フレーム `zv += (zf − zv) × 0.2`（差が 0.01 未満で止める）。ボケと opacity は README の式の `dz` を `|z − zv|` にして毎フレーム計算する。カードの `filter` には transition を付けない（JS で動かす）。`opacity` は `.3s ease`
- アクティブでない年グループ：`blur(1.8px)`、opacity 0.78
- ヒーロー：`blur = dz × 4 × 0.53`
- **ブリージング**：アクティブなグループのコンテナ（ヒーローの section／年グループのカラムの親）に `scale(1 + 0.02 × (1 − zv/den))`。`transform-origin` = ピントの合ったカードの中心（グループ内の座標。コンテナに `position:relative` を付け、`offsetLeft + offsetWidth/2`, `offsetTop + offsetHeight/2`）。中心は毎フレーム `× 0.2` で新しいカードへ寄せる（飛ばさない）。グループが替わったら中心は即座に置き換える
- **視差**：上の中心を README の「マウス位置」の代わりに使う。`mx = clamp(中心x / グループ幅 × 2 − 1)`、`my` も同様
  - Archive：README と同じ `k = 6 + 14·(1−t)` → `translate(−mx·k, −my·k·0.5) scale(1 − 0.06·t)`
  - ヒーロー：`kk = (3 − idx) × 6` → `translate(−mx·kk, −my·kk·0.6)`
  - カードの transition：`transform .8s cubic-bezier(.2,.7,.2,1)`

### レイアウト（タッチ方式・2 列のとき）
README のレスポンシブの節の「`<680px` ではメイン 1 枚＋サイド 2 枚を縦積み」を、次の値で確定します。

- ヘッダー：sticky（`top:0; z-index:30`）、`padding:18px 20px 22px`、背景 `linear-gradient(var(--bg) 55%, transparent)`。サイト名 21px。右はメニューボタン（44×44px、`aria-label="メニュー"`、2 本線の SVG）
- ヒーロー：`padding:0 20px`、縦 gap 22px
  - メイン：画像 `aspect-ratio:4/5`、テキストは `left/right/bottom:20px`、gap 10px。メタ 10px、タイトル 28px / line-height 1.25
  - サイド 2 枚：2 列グリッド（gap 14px）、画像 `1/1`、カード内 gap 8px。タイトル 16px / 1.4
- Archive：`padding:48px 20px 40px`、見出し `Archive` 40px（`padding-bottom:10px`）
  - フィルタ：横スクロール（スクロールバー非表示）、タブ gap 22px、各 `min-height:44px`。Depth of field の切替は設けない（README の 2026-11 改訂。常に On）
  - 年グループ：`padding-top:32px`、縦 gap 20px。年 30px
  - カラム：2 列グリッド（gap 14px）、カード縦 gap 26px、カード内 gap 8px。タイトル 15px / 1.45
- フッター：上罫 1px、`padding:28px 20px 80px`

## キーボード（推奨・プロトタイプ未実装）
- カードに `:focus-visible` が来たら、マウス方式・タッチ方式に関係なく AF ブラケットをそのカードに付ける（ポインタ位置は使わない）。`focusKey` もそのカードにする

## 動きを減らす設定
`@media (prefers-reduced-motion: reduce)`：
- ブラケットはばねを使わず目標へ即座に置き、opacity だけ `.2s` で切り替える
- ブリージング・視差は無効（README の視差の無効化と同じ）
- ピント送りの補間は行わず、`zv = zf`
